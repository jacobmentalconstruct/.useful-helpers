# App Journal

The app journal is chronological project memory. Older entries may describe
rules, counts, paths, or operational assumptions that were true at the time and
later superseded.

For current authority, read in this order:

1. `_docs/BCC.md`
2. `_docs/CURRENT_STATE.md`
3. `_docs/PROJECT_PLAN.md`
4. The latest numbered journal entry

Do not treat older journal entries as current operational authority unless the
latest current-state file and active BCC still agree with them.
